# Glossary

The domain language of this project. Each term gets one canonical name, a
definition with no implementation details, and the words to avoid. Add terms
as they are resolved (the `domain-modeling` skill does this during
`/grill-with-docs`).

## Language

**Note**:
A short piece of text a user writes for themselves. Only its author can see it.
_Avoid_: memo, entry

**User**:
Someone who has signed up. A user is a member or an admin; admins can see all users.
_Avoid_: account (that is a sign-in method of a user), customer
